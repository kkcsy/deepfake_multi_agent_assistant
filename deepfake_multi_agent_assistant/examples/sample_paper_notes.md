# 深度伪造检测研究笔记

当前研究关注 deepfake detection 的跨数据集泛化问题。现有方法通常从单张静态图像中挖掘局部伪影、频域异常或语义不一致，但这些特征可能与特定伪造方法或生成器高度耦合，在未知数据集上泛化能力下降。

一个可行方向是引入主动探测范式：通过 VAE 等生成式重构模块对输入图像进行受控重构，然后比较原始图像与重构图像之间的像素级、频域级和特征级差异。真实图像通常包含更多物理传感器噪声和细粒度纹理，经过生成式瓶颈后会出现更明显的表征变化；伪造图像通常更接近生成模型流形，重构前后变化较小。

论文写作中需要强调：该范式不是被动寻找静态伪影，而是通过统一的重构过程主动激发真假图像的响应差异，从而捕获更稳定的检测线索。
